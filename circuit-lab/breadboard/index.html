The Breadboard Bench

A practice breadboard for the Circuit Lab bench tasks. Wire up LEDs, resistors, switches, and logic chips, flip the switches, and watch what happens. Probe any two holes with the multimeter. Then try the challenges: build circuits that match a truth table, and fix boards that someone else wired wrong.

👋 How to use it
  1. Pick a tool (Wire, Resistor, LED…), then tap two holes to place it. For an LED, tap the + leg (anode) first.
  2. Use Select to flip switches, press buttons, change a part, or move one of its ends. Tap an empty hole to light up everything connected to it.
  3. Read the Problems box. It catches the mistakes real boards punish: unpowered chips, backwards LEDs, missing resistors, floating inputs, and shorts.
  4. Start with the challenges. Works best on a laptop or tablet; on a phone, scroll the board sideways.

Simplified model: ideal wires and switches, LEDs with a fixed turn-on voltage, 74HC chips with about 25 Ω outputs. Good for learning what works and what doesn't, not for exact readings.

    Breadboard and chip tips

    What trips people up at the real bench, and the chip pinouts you'll need.

    How the board is connected

    • Each column of 5 holes (a–e, or f–j) is one connected strip. Hover or tap a hole with Select to see its strip light up.
    • The center gap separates the top and bottom halves. Chips straddle it so each pin gets its own strip.
    • The rails run the whole length. On this board only the top rails come from the battery. The bottom rails need two jumper wires, which most starter boards already have.
    • Never put both legs of a part in the same strip: that shorts the part out.

    Chip rules

    • Notch on the left. Pin 1 is bottom-left, pins count counterclockwise, so pin 14 is top-left.
    • On every 14-pin 74HC logic chip here: pin 14 to + and pin 7 to −. No power, no logic.
    • 74HC chips run on 2–6 V. A 9 V battery will damage them.
    • Don't leave an input you're using unconnected. A "floating" input picks up noise and can read 1 or 0 at random.
    • Never wire an output straight to + or −, or to another output.
    • An output can light an LED, but always through a resistor (330 Ω is a good choice at 5 V).

    Troubleshooting order

    1. Battery voltage across the rails.
    2. Chip power: probe pin 14 to pin 7. It should read the supply voltage.
    3. Each input pin: does it change when you flip its switch?
    4. Each output pin: does it match the truth table?
    5. The LED: right way around, and a resistor in series?

    Practice this order in the fix-it challenges, using only the meter before you change anything.
